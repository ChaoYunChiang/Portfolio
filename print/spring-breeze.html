Solo project, 3 weeks. Pixel-art browser game

Longing for the Spring Breeze望春風

Role
Solo Producer
Time
3 weeks
Type
Historical shopkeeper sim
Tools
Piskel, Audacity, MusicScore, Claude (coding)
  • A first-person record-shop game set in Taiwan under martial law, made for players who may not know the history.
  • Version 1 matched song versions to devices on a timeline. Testers found it serious and moving, but it felt like a museum display.
  • Version 2 added a game loop of selling records.
  • Each day stands for a stage of martial law. Real regulations arrive one at a time, and money, rent and marks give each rule a cost.
  • Testers then found it fun and interesting, and called it a game.
